# Deploying

Free on Render + Neon, no card needed for either. About 10 minutes.

Render's own free Postgres is deliberately not used — free databases there expire 30
days after creation.

## 1. Database (Neon)

1. Sign up at [neon.tech](https://neon.tech) and create a project.
2. Copy the connection string.
3. Change the scheme from `postgresql://` to `postgresql+psycopg://` — SQLAlchemy needs
   the driver named, and it will fail at startup without it.

## 2. Backend (Render)

1. Sign up at [render.com](https://render.com) and connect this GitHub repo.
2. **New → Blueprint**, point it at `render.yaml`. It picks up both services.
3. Set these on `talentscout-api` (the blueprint marks them `sync: false`, so they are
   never committed):

   | Variable | Value |
   |---|---|
   | `ANTHROPIC_API_KEY` | from [console.anthropic.com](https://console.anthropic.com/settings/keys) |
   | `DATABASE_URL` | the Neon string from step 1 |
   | `CORS_ORIGINS` | `["https://talentscout-web.onrender.com"]` — JSON array, exact origin, no trailing slash |

   `JWT_SECRET` is generated by Render. Don't set it by hand; the app refuses to start
   with a secret under 32 bytes or one still reading `change-me`.

4. Set `VITE_API_BASE_URL` on `talentscout-web` to
   `https://talentscout-api.onrender.com/api/v1`. It is baked in at build time, so
   changing it later needs a rebuild, not a restart.

Migrations run automatically on boot (`alembic upgrade head` in the Dockerfile's `CMD`).

## 3. Check it

```bash
curl https://talentscout-api.onrender.com/health
```

Then open the web URL, create an account, and run a screening.

## Known rough edges

**Cold start.** Free instances sleep after 15 minutes idle. The first request wakes the
service (~1 minute), and question generation then takes another 30–90 seconds. Someone
opening a cold link waits a while with little feedback. Don't paper over this with a
cron pinger — it burns the 750 free instance-hours and keeps the service awake all month.

**Spend.** Both Claude calls sit behind an interviewer account, so nobody can run up
the bill without signing up. Set a budget cap in the Anthropic console anyway, and note
that account creation is currently open to anyone who finds the URL.

**Bundle size.** ~650 KB (205 KB gzipped), mostly MUI. Worth code-splitting before this
gets real traffic.
